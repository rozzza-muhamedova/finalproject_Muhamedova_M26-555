VALUTA TRADE HUB

Описание проекта: 

        ValutaTrade Hub - это консольное приложение, имитирующее платформу для отслеживания и симуляции торговли фиатными и крипто-валютами. 
        Программа позволяет пользователям регистрироваться, управлять своим виртуальным портфелем, совершать сделки купли/продажи и отслеживать актуальные курсы. 
        Проект состоит из двух логических частей: 
            - Core Service (управляет пользователями, кошельками и транзакциями);
            - Parser Service (отдельный микросервис, который обращается к публичному API CoinGecko, получает актуальные курсы криптовалют и сохраняет их в локальный кеш). 
        Все данные сохраняются на диск в формате JSON в папке data/.

Реализованные упрощения:

    Модель торговли (buy/sell):
        В проекте реализована **упрощённая модель** торговли (согласно разрешению преподавателя), по которой
        buy и sell меняют только баланс торгуемой валюты, а стоимость в USD выводится как оценочная.

    Парсер-сервиc:
        Реализован только клиент для CoinGecko (криптовалюты). Клиент для фиатных валют (ExchangeRate-API) не реализован, так как требует регистрации и персонального API-ключа и работает нестабильно.

    Хранение истории курсов:
        Файл data/rates.json работает как кеш последнего обновления. При каждом обновлении данные в нём полностью перезаписываются (хранится только актуальный курс и время обновления). Файл исторических данных exchange_rates.json не реализован.


Архитектура и реализованные концепции: 

    В проекте реализована иерархия валют (наследование и полиморфизм) — создан абстрактный класс Currency и наследники FiatCurrency и CryptoCurrency;
    для получения валюты по коду используется фабрика get_currency(). 

    Добавлены пользовательские исключения: InsufficientFundsError, CurrencyNotFoundError, ApiRequestError для точной обработки ошибок в CLI. 

    Реализован паттерн Singleton — класс SettingsLoader (в infra/settings.py) гарантирует, что настройки (пути к файлам, TTL) загружаются один раз и доступны из любой точки программы. 

    Написан декоратор @log_action, который применяется к функциям buy и sell: он логирует действие, пользователя, валюту, сумму и результат в файл logs/actions.log с ротацией. 

    Реализован микросервис (Парсер): класс CoinGeckoClient (наследник BaseApiClient) выполняет GET-запрос к API CoinGecko, а класс RatesUpdater координирует процесс обновления и сохранения данных в rates.json. 

    Реализовано кеширование (TTL): в get-rate происходит проверка времени последнего обновления, и если данные старше 5 минут (300 секунд), программа просит пользователя выполнить update-rates.


Инструкция по установке и запуску: 

    1. Для работы с проектом необходим инструмент uv. 
    2. Откройте терминал, склонируйте репозиторий командой git clone <ссылка_на_репозиторий>, перейдите в папку проекта. 
    3. оберите пакет и установите его глобально: uv build и затем uv tool install dist/*.whl --force. 
    4. Запустите приложение командой valutatrade-hub. (Также можно запустить локально без установки: uv run python main.py).
    
    
Функции (Команды):

    register <username> <password> — создать нового пользователя.
        Пример использования:
        >>>Введите команду: register --username alice --password 1234
        Пользователь alice зарегистрирован (id=1). Войдите: login --username alice --password **** 
        
    login <username> <password> — войти в систему.
        Пример использования:
        >>>Введите команду: login --username alice --password 1234
        Вы вошли как 'alice'    
        
    show-portfolio — показать все кошельки и итоговую стоимость.
        Пример использования:
        >>>Введите команду: show-portfolio
        Портфель пользователя 'alice' (база: USD):
        - BTC: 0.0500 →  3791.30 USD
        - USD: 100.0000 →  100.00 USD
        ---------------------------------
        ИТОГО: 3,891.30 USD
        
    buy <currency> <amount> — купить валюту (по оценочному курсу).
        Пример использования:
        >>>Введите команду: buy --currency BTC --amount 0.05
        Покупка выполнена: 0.05 BTC по курсу 75826 USD/BTC
        Изменения в портфеле:
        - BTC: было 0.0000 → стало 0.0500
        Оценочная стоимость покупки: 3791.30 USD
        
    sell <currency> <amount> — продать валюту.
        Пример использования:
        >>>Введите команду: sell --currency BTC --amount 0.02
        Продажа выполнена: 0.02 BTC по курсу 75826 USD/BTC
        Изменения в портфеле:
        - BTC: было 0.0500 → стало 0.0300
        Оценочная выручка: 1516.52 USD
        
    get-rate <from> <to> — получить курс валюты из локального кеша (с учетом 5-минутного TTL).
        Пример использования:
        >>>Введите команду: get-rate --from BTC --to USD
        Курс BTC_USD: 75826 (обновлено: 2026-11-07T16:10:35.453786)
        Обратный курс USD_BTC: 0.00001319
        
    update-rates — запустить Парсер для обновления курсов с CoinGecko.
        Пример использования:
        >>>Введите команду: update-rates
        Update successful. Total rates updated: 3
    
    eit - выход из программы.
        
    Обработка ошибок:
        Примеры:
        >>>Введите команду: buy --currency ASDFG --amount 1
        Ошибка при покупке: Неизвестная валюта 'ASDFG'. Проверьте код валюты.

        >>>Введите команду: sell --currency BTC --amount 100
        Ошибка при продаже: Недостаточно средств: доступно 0.0300 BTC, требуется 100.0 BTC.
        Общие команды: help — справочная информация, exit — выход из программы.
